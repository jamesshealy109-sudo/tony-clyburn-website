# Tony Clyburn — Website Refresh

A high-energy, editorial refresh for broadcaster, speaker, host, voice actor, and community connector Tony Clyburn.

## Live website

### [View Tony Clyburn's live website →](https://jamesshealy109-sudo.github.io/tony-clyburn-website/)

The public website requires no account or sign-in.

## Direction

The experience pairs Tony's crisp, clear voice with a warm editorial identity: midnight navy, brick red, warm ivory, archival photography, Columbia landmarks, strong typography, and a clear path to start a conversation.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm run start
```

## Launch notes

- Connect the inquiry form to Tony's preferred email or CRM before launch.
- Confirm the social profile URLs before launch.
- Replace the current domain's DNS or publishing target only after final approval.
- Source photography is stored in `public/images`; the custom share card is `public/og.png`.

## Stack

- Next.js-compatible app router via Vinext
- React 19
- TypeScript
- OpenAI Sites / Cloudflare deployment configuration
